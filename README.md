# Tone Control (5-Band Stereo L/R & Both, No Notification)
Stock Android Tone Control (`Lowest`, `Low`, `Mid`, `High`, `Highest`, `-16 dB` to `+16 dB`) with independent channel modes (`Both (L + R)`, `Left (L)`, `Right (R)`), presets (`Neutral`, `FixMuddy`, `FixSharp`, `FixBoth`), Save/Delete template support, and silent background execution.
